# Project Overview

## Product

Cortex Global is a website for a global network of local hubs, education, events, services, and real projects around emerging technology.

The website should communicate:

- what Cortex Global is
- why local hubs matter
- what services exist
- who is involved
- where events and chapters are active
- how people can join, support, or contact the network

## Primary Audience

- newcomers who need a clear onboarding path
- builders looking for community, support, or collaboration
- partners and sponsors evaluating the network
- regional leads and event organizers
- Monad and ecosystem participants who need context

## Website Scope

Core sections:

- Hero: nav, headline, brand pattern or shader-backed first impression, primary CTA
- Mission: concise story and Cortex purpose
- Services: service cards, shader surfaces, clear labels
- Team: people, roles, and regional context
- Events: locations, event types, and upcoming/past activity
- History: milestones and network evolution
- Footer: navigation, contact, newsletter or social links

## Source Documents

- `skills/BRAND.md`: brand behavior, voice, copy, naming, logo rules, and asset generation
- `skills/DESIGN.md`: design-system tokens, component contracts, gradients, shader recipes, and Tailwind/shadcn mapping
- Figma `cortex-web`: website composition and component work-in-progress, https://www.figma.com/design/LmIBDGjK2TIR46y9zt92Zr/cortex-web?node-id=0-1&t=0VnmQRA5D2mNVbsS-1
- Figma `guideline`: official brand colors, typography, gradients, logo, and visual language

## Non-Goals

- Do not build a generic SaaS marketing site.
- Do not make a dashboard or app shell unless the request explicitly changes scope.
- Do not create one-off visual rules inside page sections when they belong in `skills/DESIGN.md`.

## Product Principles

- Lead with the actual website experience, not a marketing explanation of the experience.
- Keep copy concrete and grounded.
- Prefer structured density over decorative empty space.
- Make global scale visible through local hubs, events, and network graphics.
- Preserve Cortex Orange as the main action signal.
